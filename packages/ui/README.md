# kinkstar_ui

Shared theme, Lucide icons, and the config loader for the user and host apps.

- `lib/src/theme/user_theme.dart` — user dark tokens
- `lib/src/theme/host_theme.dart` — host light tokens
- `assets/config/config.json` — copy of `mock/config.json` from `feature/mock-data`

The package name is `kinkstar_ui` so it does not collide with `dart:ui`.
